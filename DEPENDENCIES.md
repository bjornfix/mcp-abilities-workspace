# Dependencies

- [WordPress 6.9+](https://wordpress.org/documentation/wordpress-version/version-6-9/) provides the WordPress runtime and registered Abilities API.
- [PHP 8.0+](https://www.php.net/releases/8.0/en.php) provides the required server runtime.
- [WordPress Abilities API](https://developer.wordpress.org/apis/abilities-api/) owns ability registration, schemas, annotations, and authorization callbacks.
- [WordPress MCP Adapter](https://github.com/WordPress/mcp-adapter) exposes registered WordPress abilities to authenticated MCP clients.
- [MCP Expose Abilities](https://devenia.com/plugins/mcp-expose-abilities/) provides the Devenia transport policy for the registered abilities.
- [Google Workspace Gmail API](https://developers.google.com/workspace/gmail/api/reference/rest) provides the mailbox, message, thread, attachment, label, and sending operations used through the configured Workspace identity.
